# Cosmo App Accessibility Statement

**Effective Date:** January 26, 2025

**Last Updated:** January 26, 2025

## Our Commitment to Accessibility

Vengeance Intelligence LLC is committed to ensuring that the Cosmo app is accessible to all users, including those with disabilities. We strive to provide an inclusive experience that allows everyone to enjoy our astrological services.

## Accessibility Standards

We aim to conform to the Web Content Accessibility Guidelines (WCAG) 2.1 Level AA standards and follow mobile accessibility best practices to ensure our app is usable by people with various abilities and assistive technologies.

## Current Accessibility Features

### Visual Accessibility
- **High Contrast Support:** The app supports high contrast mode for better visibility
- **Text Scaling:** Text can be scaled up to 200% without loss of functionality
- **Color Independence:** Information is not conveyed through color alone
- **Dark Mode:** Available dark theme reduces eye strain and improves readability
- **Large Touch Targets:** Interactive elements meet minimum size requirements (44x44 points)

### Motor Accessibility
- **Voice Control:** Compatible with iOS Voice Control and Android Voice Access
- **Switch Control:** Supports external switch devices for navigation
- **Gesture Alternatives:** All gestures have alternative input methods
- **Touch Accommodations:** Supports touch accommodations for users with motor difficulties

### Cognitive Accessibility
- **Clear Navigation:** Simple, consistent navigation structure
- **Plain Language:** Content is written in clear, easy-to-understand language
- **Error Prevention:** Clear error messages and validation feedback
- **Consistent Layout:** Predictable interface patterns throughout the app

### Hearing Accessibility
- **Visual Alerts:** All important information is presented visually
- **No Audio-Only Content:** All content is available in text format
- **Vibration Support:** Haptic feedback for important notifications

## Assistive Technology Support

### Screen Readers
- **iOS VoiceOver:** Fully compatible with VoiceOver for iOS
- **Android TalkBack:** Compatible with TalkBack for Android
- **Semantic Labels:** All interactive elements have descriptive labels
- **Heading Structure:** Proper heading hierarchy for easy navigation

### Voice Control
- **Voice Commands:** Supports voice commands for main functions
- **Dictation:** Text input fields support voice dictation
- **Voice Navigation:** Voice control for app navigation

### Switch Control
- **External Switches:** Compatible with external switch devices
- **Customizable Scanning:** Adjustable scan timing and highlighting
- **Multiple Switch Support:** Supports single and multiple switch configurations

## Known Limitations

While we strive for full accessibility, we acknowledge some current limitations:

1. **Complex Charts:** Some detailed astrological charts may not be fully accessible to screen readers
2. **Third-Party Content:** Some external content may not meet accessibility standards
3. **Older Devices:** Some accessibility features may be limited on older devices
4. **Custom Fonts:** Some decorative fonts may not be optimal for all users
